Digital Store

A responsive e-commerce web application built with React and Tailwind CSS.

✨ Features :

-Browse products

-Search products

-Filter products by category

-Sort products

-View product details

-Add and manage products in the shopping cart

-Login and sign-up forms

-Contact form

-Form validation

-Error handling with Error Boundary

-Toast notifications

-Responsive design

-Fetch and manage data from APIs


🛠️ Technologies :

-React

-Vite

-Tailwind CSS

-Axios

-Formik

-Yup

-Lodash

-React Toastify

-Lucide React


📄 Pages :

-Home

-Products

-Product Details

-Shopping Cart

-Login

-Sign Up

-About Us

-Contact Us


🚀 Getting Started :

Installation :

npm install 

Run the project:

npm run dev
